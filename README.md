# Bulletproof Personal Training

Four-page HTML/CSS site. Home, Media, Services, and About.

Published: https://vandyparkes.github.io/capstone-project/site/

Repository: https://github.com/vandyparkes/capstone-project

Open `site/index.html` locally. The root `index.html` sends the browser to `site/`.

## Files

- `site/` pages, `css/`, `fonts/`, `images/`.
- `site/css/main.css` loads reset, base, layout, components, utilities, states, overrides, then print.
